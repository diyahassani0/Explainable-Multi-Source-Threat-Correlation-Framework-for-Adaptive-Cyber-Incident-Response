Data Preprocessing & Methodology Specification
Transparent engineering of the given 1,200 cybersecurity incidents
1. Data Cleaning & Normalization

Resolved label fragmentation by standardizing Malware_Attacks (36 rows) to Malware. Handled whitespace padding and validated numerical bounds across INR losses.

2. Ground-Truth Risk Scoring

Because raw logs lack arbitrary severity labels, severity is calculated using standard NIST SP 800-61 / FIRST CVSS impact scoring: 55% Financial Loss + 25% Sector Sensitivity + 20% Vector Blast Radius.

3. Feature Matrix Construction

Extracted numerical transforms (Financial_Loss_Log), domain sector weights, and encoded categorical features for multi-class classification in XGBoost.

Axiomatic Attribution in Cyber Risk

SHAP (SHapley Additive exPlanations) grounds predictive interpretations in cooperative game theory, ensuring Efficiency, Symmetry, and Additivity.

• Financial Loss (Amount_Lost_INR): Consistently top driver (+ve SHAP push) when loss exceeds >INR 320,000.
• Sector Criticality (Category): Elevates baseline expectation for Government, Health, and Financial entities due to high social blast radius.
• Explaining Correlation: Multi-source alerts correlated via shared C2 IP and temporal burst provide corroborating evidence reducing false-positive likelihood.
